# Data Engineering

Construir y mantener la infraestructura y los procesos que permiten que los datos fluyan de forma fiable desde sus fuentes originales hasta los sistemas donde analistas y científicos de datos pueden utilizarlos. En esencia, se encargan de que los datos estén disponibles, limpios, estructurados y sean accesibles para la toma de decisiones y la analítica avanzada
